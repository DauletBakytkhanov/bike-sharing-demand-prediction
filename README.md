# Bike Sharing Demand Prediction

## Project Description

This project focuses on predicting hourly bike rental demand using Machine Learning.

The goal is to predict the total number of rented bikes based on temporal and weather conditions.

## Dataset

Source: UCI Machine Learning Repository
https://archive.ics.uci.edu/dataset/275

Dataset: Bike Sharing Dataset
Main file: hour.csv

Target variable: cnt

Task: Regression
